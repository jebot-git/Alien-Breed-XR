# Alien Breed 3D XR icon

Authored with the built-in imagegen tool for this port, 2026-10-27. This is new
launcher artwork inspired by the game's industrial sci-fi presentation, rather
than an extracted game sprite or recovered original icon. Existing game/art
notices remain unchanged.

The selected transparent RGBA master is `alien-breed-xr-master.png` (1254 square).
The hicolor tree contains 16, 24, 32, 48, 64, 96, 128, 256, 512 and 1024 pixel PNGs.
Compile those exports with `sh xr/tools/build-icon.sh` (ImageMagick is needed only
for asset authoring, not when playing or installing the game).

The desktop icon name and SDL application identity are `alien-breed-xr`.
The 256 pixel export is also staged beside game data for SDL window icons.
Keep alpha when resizing; do not bake a background into the exports.
